What you need

  • An Atari ST, STE, Mega ST or Mega STE (PAL, 50 Hz) with a colour monitor.
  • A SidecarTridge Multi-device with this app installed from Booster, the Multi-device's app manager: it downloads the app and its updates from the SidecarTridge store, so there is no file to install by hand.
  • A microSD card with about 51 MB free. The app reads the card at 8 MHz or more: set the SD card's speed in Booster if it is lower.
  • A computer with a web browser, to make the card's files.

Making the card's files

  1. Download the Amiga port's repository as a zip, at the commit this port was tested with: chorensha-40fec7d.zip (about 280 MB).
  2. On the first page, drop the zip and choose Make the files. Everything happens in the browser; nothing is uploaded.
  3. Choose Write them to the card and pick the card's top folder: the files go into its CHORENSHA folder. In a browser that cannot write to a folder, download CHORENSHA.zip instead and unzip it onto the card.

The page makes the game's images for this release of the app and its sound for every machine, so the same card plays on an STE and on a plain ST. After updating the app, make the files again: each release's images fit only its own firmware. The page says which firmware its files are for, and the cartridge shows its own on the ST.

Starting the game

Put the card in the Multi-device and switch the ST on: it starts to the GEM desktop. Open the cartridge's drive, c:, and start GAME.TOS.

If the card is not ready, the game shows why, in red, with a QR code that opens the page for this release. It checks the card again every second, so the game starts as soon as the files are there: take the card out, make the files, put it back. ESC goes back to the desktop, B starts Booster.

GAME.TOS itself may say, before the game starts, that high resolution is not supported (use a colour monitor) or that there is not enough free memory (start without accessories or a RAM disk).

Plug the joystick into joystick port 1, the port the mouse does not use.

After leaving for GEM, start GAME.TOS again to play: the game starts over at its title. The cartridge's SELECT button restarts the Multi-device (reset the ST afterwards); held while the ST is switched on, it starts Booster instead of the game.

The title

ItemWhat it does
STARTa new game from stage 1
CONTINUEa game from the stage where the last game ended (or the hidden menu's STAGE and ACCHO)
CONFIGthe options (below)
KAKUSIthe hidden menu (below); K on the title opens it too
GEM DESKTOPleave for the GEM desktop
BOOSTERreturn to Booster

Left alone, the title shows the high scores and then the demo; any input brings the title back. The bottom line shows the original game's version and this port's.

A new ship comes every 1,000,000 points. When the last one is lost, the game is over; a score good enough for the high-score table asks for a name: move the cursor over the letters with the joystick, press fire to add one, and choose ED to finish. The table is kept on the microSD card, as SCORE.DAT in the app's folder, /CHORENSHA.

CONFIG

Up and down choose an item; left and right change a number; fire plays or toggles. The options are not saved: an ST reset or switching off sets them back.

ItemWhat it does
PCM PLAYthe sound test: fire plays sound effect N (0 to $FF)
BGM PLAYthe music test: fire plays song N (0 to $3F), the second button stops it
SHOT=A BOMB=Bswaps the two buttons (fire and Alternate bomb, space shoots)
SILENT MODEturns the sound effects off (the music plays on)

The hidden menu

KAKUSI MODE. The original opens it from CONFIG with the pad's up, down and right held together, which a joystick cannot do: this port has KAKUSI on the title and the K key instead. Values are shown in hexadecimal. STAGE, ACCHO, KASEGI, BOSS_ONLY, TD_SPEED and JK_SPEED apply to the next game, START or CONTINUE; MUTEKI and DEBUG at once.

ItemDefaultValuesWhat it does
MUTEKI00, 1invincibility
STAGE10 to Fwhere CONTINUE starts: 1 to 7 the stages, 0 the game's stage 0, F the SHOW TIME stage; 8 to E move to the next round's stage 1
ACCHO00 to Fthe round (loop). After stage 7 an even round goes on to the next round; an odd round plays a last part and ends the game (MISSION COMPLETE). From round 1 enemies fire back when they are destroyed, and the enemies change with the round
TD_SPEED$100 to $3C, step 4the enemies' bullet speed: $10 is normal, $20 twice as fast, 0 stops them
JK_SPEED$300 to $78, step 8the ship's speed: $30 is normal; under $10 the ship cannot move
BOSS_ONLY00, 1every stage starts at its boss
DEBUG00 to 3the debug mode (below)
KASEGI00, 1the scoring mode: power-ups taken at their maximum build counters (shown on screen) that multiply the points of each kill, and losing the power-up clears them
EXITback to the title

DEBUG (any value but 0): TAB freezes the game, TAB again steps one frame and ESC goes on; CTRL and SHIFT pressed together (and let go) give one step of every power-up and a stock; the 1 key ends the stage's current part at once; each kill's points are shown. DEBUG 1 also shows the sprite count, the RANK (the difficulty, which rises with time), the stage's part (ALG_SW) and its frame count (TOTAL_CT). Holding fire and space while the game starts turns DEBUG 1 on as well.

Two of the original's items are left out: VWAIT (the VBLs the game waits for each frame, 1; more is slow motion on the X68000, but this port shows a frame every VBL whatever the wait) and SAVE DEMO.REP (the last game saved as the demo: this port keeps the demo it loaded).
